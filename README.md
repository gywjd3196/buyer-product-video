# 바이어 제품 영상

PYDERIN 제품별·국가별 반응형 영상 라이브러리. GitHub 저장소는 비공개이며 배포 사이트는 별도로 운영합니다.

## 실행 및 검증

```sh
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
node scripts/check.mjs
```

`http://127.0.0.1:4173`에서 확인합니다. 외부 의존성 설치와 빌드가 필요 없는 HTML/CSS/JavaScript 사이트입니다. 제품/국가 상세 경로는 해시 라우팅을 사용해 공유 링크와 새로고침을 지원합니다.

## 데이터 확인 결과 — 2026-10-21

- 원본 Google Sheets의 전체 19개 탭을 검사했습니다.
- 중복을 제거한 Instagram 게시물 링크 263개: 시트 국적 기준 일본 131개, 대만 132개.
- 제품 정보가 있는 게시물 123개를 7개 제품에 연결했습니다. 제품이 여러 개인 게시물은 각 제품에 함께 표시합니다.
- 제품명이 없는 140개 게시물은 국가별 목록에만 포함합니다. 팔로워나 약국명에서 제품을 추정하지 않습니다.
- Instagram DM 링크 7건과 다른 플랫폼 링크 31건은 Instagram 게시물 카탈로그에서 제외했습니다. 이 수치는 원본 내 등장 횟수이며 고유 게시물 수가 아닙니다. Threads 링크는 영상 여부/조회수가 확인되지 않아 순위에 섞지 않았습니다.
- 링크가 `/p/`인 경우 사진·캐러셀·영상 모두 가능하므로 `mediaType: unverified`로 보존했습니다. `/reel/`도 조회수를 확인하기 전에는 순위에 포함하지 않습니다.
- 원본에는 조회수 열이 없습니다. 팔로워(F/W), 좋아요, 비용은 조회수로 사용하지 않았습니다. 비고의 ‘리쥬올 광고 조회수 45만’은 이 게시물의 확정 조회수가 아니므로 사용하지 않았습니다.
- Instagram 공개 게시물과 HTML에서 조회수를 확인하지 못했습니다. 현재 확정 순위는 없으며 참고 게시물을 시트 순서대로 제품별 최대 3개, 국가별 최대 5개 표시합니다. UI에 이 제한을 명시했습니다.
- 메인 시트 O139는 표시된 게시물 URL과 실제 하이퍼링크(프로필)가 다릅니다. 표시 문자열에 명시된 게시물 URL을 보존했으며 실제 영상/제품/조회수 재확인이 필요합니다.
- 수딩 팩처럼 제품명이 모호한 행은 제품에 임의 연결하지 않았습니다. ‘리셋미네랄마스크’는 공식 명칭의 클리어부스터 스킨 리셋 미네랄 마스크로 연결했고 명백한 ‘리쥬뷰스터’ 오타를 정규화했습니다.

## 조회수 추가

정확한 조회수와 확인일, 근거 URL, 영상 여부가 확인된 자료가 필요합니다. CSV 형식:

```csv
id,views,checked_at,source_url,media_type
```

실제 측정값으로 행을 채운 뒤 다음을 실행합니다. 예시 숫자를 실제 데이터로 넣지 마세요.

```sh
python3 scripts/import_metrics.py /absolute/path/to/verified-metrics.csv
node scripts/check.mjs
```

정수 조회수·영상 여부·확인일·출처가 모두 있는 영상만 정렬합니다. 일부 게시물만 확인된 상태에서는 ‘조회수가 확인된 영상’으로 표시하며 전체 TOP이라고 주장하지 않습니다. 모든 후보를 확인한 경우 제품별 TOP 3, 국가별 TOP 5가 됩니다. 자동 실시간 수집은 구현되어 있지 않습니다.

## 원본 재분석

`scripts/inspect_sheet.py`는 `/tmp/buyer-source.xlsx`를 읽어 `/tmp/buyer-sheets.json`에 임시 추출합니다. `scripts/prepare_data.py`는 임시 추출본과 `/tmp/pyderin.html`의 공식 제품 JSON-LD에서 공개용 데이터와 이미지를 생성합니다. 재생성은 기존 조회수 정보를 초기화하므로 이후 검증된 지표를 다시 가져와야 합니다. 원본 임시 파일에는 개인정보가 포함될 수 있어 저장소 밖에서만 다룹니다.
