## 현재 디자인과 화면 이동

2026-10-26 수정: 12개 섹션의 구조와 기존 영상·번역·제품·연구 자료를 유지하고, 화면별로 읽는 프레젠테이션 방식으로 정리했습니다.

- 원본 전체 화면 히어로 영상은 유지합니다.
- `presentation.css`: 흰색·따뜻한 회색·차콜 배경, 얇은 구분선, 실제 사진과 절제된 붉은색 강조. 큰 배경 글자, DNA 배경, 겹친 제품, 기울임·패럴랙스·순차 등장 효과를 제거합니다.
- `presentation.js`: 한 번의 세로 휠/트랙패드 제스처마다 다음 읽기 화면으로 이동합니다. 관성 입력은 같은 제스처로 처리합니다. 모바일 세로 스와이프, PageUp/Down·상하 방향키·Space·Home/End, 우측 섹션 메뉴도 지원합니다.
- 02의 제품 탐색과 원료 연구는 두 개의 별도 읽기 화면입니다. 12개 상위 섹션 번호는 유지합니다.
- 펼친 상세 자료나 작은 화면에서 길어진 내용은 추가 정지점을 만들어 순서대로 읽습니다. 가로 표 스크롤, 폼 입력, 영상 조작과 접근성 키보드 탐색을 보존합니다.
- 동작 줄이기 설정에서는 화면 전환 애니메이션을 생략합니다. JavaScript가 없거나 조작하지 않아도 본문은 일반 문서로 남습니다.
- 연속 휠 입력이 잠기지 않도록 새로운 스와이프·방향 전환·반복 마우스 입력을 구분합니다. 화면 전환 중 들어온 새로운 이동 요청은 한 개까지 유지하며, 고정 헤더 위에서도 스크롤할 수 있습니다.
- `opening.js`: 제품 사진을 한 개씩 보여주는 선택 버튼과 좌우 키 조작, 언어별 제품명을 관리합니다.
- `redesign.css` · `redesign.js` · `translations.js`: 기존 콘텐츠 스타일, 공통 헤더, 언어 선택, 한국어·영어·일본어·대만 번체 중국어를 지원합니다. 선택한 언어와 읽던 위치를 보존합니다.
- `opening.css` · `continuity.css` · `continuity.js`는 이전 연출의 참고 파일이며 현재 페이지에서는 불러오지 않습니다.

2026-10-27 인터랙션: `brand-motion.css`와 `brand-motion.js`는 영상 다음 제품 소개 화면, 03, 08, 10에만 연출을 추가합니다.

- 제품 탐색: 제품별 조명·배경 톤, 선택 전환, 포인터에 반응하는 작은 기울임.
- 국내 성장: 2,000+ 카운트와 실제 매장 사진 3장 탐색. 사진 안의 버튼은 터치·키보드로도 조작할 수 있습니다.
- 제품 비교: 원래 수치에 비례한 막대 등장, 선택한 제품과 PYDERIN의 동시 강조.
- 글로벌 진출: 대륙 선택에 따른 지구본 회전과 경로 강조. 남아프리카공화국의 진출 준비 상태와 점선 경로를 유지합니다.
- 진입 연출은 화면 도착 뒤 시작하며 스크롤을 차단하지 않습니다. 지도는 전환 후 또는 화면을 벗어나면 애니메이션을 멈춥니다. 동작 줄이기 설정에서는 최종 상태를 바로 보여줍니다.
- `assets/world-land.json`은 [Natural Earth의 110m 육지 데이터](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson)로 만든 간략화된 육지 점 좌표입니다. 지도는 이 로컬 파일만 읽으며 외부 지도 서비스를 호출하지 않습니다.

미리보기는 저장소 루트에서 다음 명령으로 실행합니다. 이미 4181 서버가 실행 중이면 그대로 사용합니다.

```sh
python3 -m http.server 4181 --bind 127.0.0.1 --directory pyderin-deck
```

http://127.0.0.1:4181/ 에서 확인합니다. `?lang=en#s8`처럼 언어와 섹션을 지정할 수 있습니다. `assets/`에는 실제 로고·제품 사진·매장 영상에서 추출한 사진과 Pretendard 서체를 보관합니다.

## 브랜드 영상 편집

`film-refined.mp4`는 현재 히어로에 사용하지 않는 편집 시안입니다. 원본의 물·미세 장면·실험실·제품·브랜드 순서를 유지하면서 화면 구도와 타이포그래피를 다시 편집한 버전입니다. 기존 영상과 실제 제품 사진만 사용합니다.

- 원본과 같은 약 40.87초, 1920×1080, 30fps.
- 기존 중앙 카운트와 큰 문구는 측면 장면을 선택해 덜어내고 별도 타이포그래피로 정리.
- 완제품의 순도와 혼동하지 않도록 99%는 PDRN **원료 순도**로 표기.
- 원본 음원은 재인코딩 없이 그대로 보존하며, 오디오 패킷 해시가 일치하는지 확인했습니다.
- 영상의 문구·음성은 기존과 같이 영어입니다. 본문의 4개 언어 전환과 별개입니다.

편집용 타이포그래피와 제품 구성 PNG는 `assets/film/`에 있습니다. FFmpeg가 설치된 환경에서 저장소 루트에서 재생성합니다.

```sh
python3 scripts/refine_brand_film.py
```

PNG의 디자인 소스는 `scripts/render_brand_film_art.cjs`입니다. Playwright가 설치된 Node 환경과 위의 로컬 미리보기 서버를 사용합니다. 필요하면 `CHROME_PATH`로 Chrome 실행 파일을 지정할 수 있습니다.

02~12 구간은 핵심 메시지와 수치를 먼저 보여주며, 특허·상세 비교·논문은 펼쳐보기로 제공합니다.
`?lang=en#s8`처럼 언어와 섹션을 지정해 미리볼 수 있습니다. 브랜드 영상의 음성은 원본 영어를 유지합니다.

저장소 최상위 폴더에서 실행합니다.

```sh
python3 -m http.server 4181 --bind 127.0.0.1 --directory pyderin-deck
```

브라우저에서 http://127.0.0.1:4181 을 엽니다.

## 본인 Vercel 계정으로 배포

Vercel에서 새 프로젝트를 만들고 `gywjd3196/buyer-product-video` 저장소를 연결합니다.

- Root Directory: `pyderin-deck`
- Framework Preset: `Other`
- Build Command: 없음 (빈 값)
- Output Directory: `.`

이 폴더의 `vercel.json`이 프레임워크·빌드·출력 설정을 지정합니다.
배포 후 생성되는 새 주소로 운영하며, 연결한 배포 브랜치의 변경 사항이 자동 배포됩니다.
기존 `pyderin-deck.vercel.app` 주소를 그대로 쓰려면 원래 Vercel 프로젝트의 소유자와 프로젝트 이전 또는 권한 공유를 진행해야 합니다.

Vercel 공식 문서: https://vercel.com/docs/builds/configure-a-build

기존 바이어 영상 사이트는 저장소의 `dist/`와 `.openai/hosting.json` 설정을 그대로 사용합니다.
두 사이트의 배포 대상 폴더를 혼동하지 않도록 합니다.

## 스크롤 회귀 확인

4181 미리보기를 데스크톱 폭으로 연 상태에서 `orca tab list --json`의 페이지 ID를 사용합니다.
`node scripts/verify_deck_scroll.cjs <페이지-ID>`는 실제 페이지에 휠 이벤트를 보내 관성, 연속 입력, 방향 반전, 전환 중 입력, 헤더 및 기본 폼 조작을 확인합니다. 미리보기의 위치는 제품 탐색 화면으로 돌아갑니다.

`node scripts/verify_deck_motion.cjs <페이지-ID>`는 제품·사진 선택, 비교 강조와 데이터 비율, 지도 회전·정지, 대륙 키보드 이동을 확인합니다.
